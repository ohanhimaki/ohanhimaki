# local-dev

Tässä kansiossa kehittäjä voi käsitellä lyhyen lifecyclen asioita, esim: Ilmoitus bugista tai tietoa päivän logeista. Voidaan myös tehdä toimintasuunnitelmaa ja ai voi tänne koostaa taskin läpiviennin ohjeita.

Kansio on kehittäjäkohtainen, eikä sen kanssa ole välttämätöntä käyttää gittiä, eikä git remotea.
